## 一、E-13 PATH 条目质量（实测）

### 1.1 用户级 PATH（长度 814，24 条）

存在问题的条目：

| 问题 | 条目 |
| --- | --- |
| 空条目 ×2 | `;;`（会解析为当前工作目录，属安全隐患） |
| 重复 | `C:\Program Files\Huawei\DevEco Studio\bin` 出现 2 次；`C:\Users\22320\AppData\Roaming\npm` 出现 2 次 |
| 多余尾部反斜杠 | `C:\Program Files\MySQL\MySQL Server 8.0\bin\` |

### 1.2 系统级 PATH（长度 655，22 条）

| 问题 | 条目 |
| --- | --- |
| **损坏段（被截断的环境变量）** | `%SystemRo` 与 `t%\system32` —— 原本是一个 `%SystemRoot%\system32`，被误拆分录入 |
| 空条目 ×1 | `;;` |
| 重复 | `C:\Program Files\Java\jdk-21\bin` 2 次；`C:\Users\22320\AppData\Roaming\npm` 2 次 |
| 与项目无关的残留 | `D:\二次元射击\二次元射击` |

补充事实：系统级 PATH 中**没有**独立的 `C:\WINDOWS\System32` 条目（只有 `C:\WINDOWS\System32\Wbem`），system32 目前靠用户级条目生效；一旦用户级被清理而未补系统级，`cmd`/`powershell` 等基础命令会失联。**修复时必须先补齐系统级 `%SystemRoot%\system32`，再删损坏段。**

### 1.3 对照 E-13 判定

- 判定：**FAIL**（存在 2 条损坏路径段，且拆分后无任何有效目录指向 system32）。
- 影响面：非阻塞（当前命令可用），但属配置缺陷，会让新装工具出现"命令找不到"的随机现象。

### 3.1 E-13 系统级 PATH（**需管理员权限**）

```powershell
$m = [Environment]::GetEnvironmentVariable('Path','Machine')
# 1) 先把 system32 补成正常条目，再剔除损坏段与空项（用字面替换，避免正则转义踩坑）
$m = $m.Replace('%SystemRo;t%\system32;', '%SystemRoot%\system32;')
$m = $m.Replace('%SystemRo;t%\system32',  '%SystemRoot%\system32')
$items = $m -split ';' | Where-Object { $_.Trim() -ne '' } | ForEach-Object { $_.TrimEnd('\') }
$items = $items | Select-Object -Unique
[Environment]::SetEnvironmentVariable('Path', ($items -join ';'), 'Machine')
```

### 3.2 E-13 用户级 PATH（普通权限即可）

```powershell
$u = [Environment]::GetEnvironmentVariable('Path','User')
$items = $u -split ';' | Where-Object { $_.Trim() -ne '' } | ForEach-Object { $_.TrimEnd('\') }
$items = $items | Select-Object -Unique
[Environment]::SetEnvironmentVariable('Path', ($items -join ';'), 'User')
```

### 3.3 E-10 关闭 python 别名 + 补 python3.exe

方式 A（推荐，界面操作为主，最稳）：
1. 设置 → 应用 → 高级应用设置 → 应用执行别名 → 关闭 `python.exe` 与 `python3.exe` 两个开关；
2. 之后 `python` 会解析到 `D:\miniconda3\python.exe`；
3. 复制一份 `D:\miniconda3\python.exe` 为 `python3.exe`（同目录），使 `python3` 也可用。

方式 B（命令行，等价）：

```powershell
# 关闭别名（按当前用户，无需管理员）
Remove-Item "$env:LOCALAPPDATA\Microsoft\WindowsApps\python.exe"  -Force -ErrorAction SilentlyContinue
Remove-Item "$env:LOCALAPPDATA\Microsoft\WindowsApps\python3.exe" -Force -ErrorAction SilentlyContinue
# 补 python3.exe
Copy-Item 'D:\miniconda3\python.exe' 'D:\miniconda3\python3.exe' -Force
```
