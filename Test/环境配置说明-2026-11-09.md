## 二、冲突规避思路（为什么不会影响你其他软件）

1. **不删任何东西，只调顺序**。`WindowsApps` 没有被删除或禁用，只是排到了用户 PATH 最后一个 —— 想还原，把它挪回第 3 位即可。
2. **不做目录瘦身**。`D:\二次元射击\二次元射击`、`C:\mingw64\bin`、MySQL、JDK、Docker、Ollama、DevEco、Trae、CodeBuddy、JetBrains 等条目**一条都没动**，即使看着冗余也不删，避免"清理完某个软件突然找不到命令"。
3. **只改用户级，不碰系统级**。系统 PATH 影响所有用户和所有服务，非管理员环境下一律不动；本次也确实没动。
4. **写入前做集合相等校验**。以「唯一目录集合」比对：修改前 20 个、修改后 20 个，`Compare-Object` 确认**零丢失、零新增**才写入；写入后立即回读比对，不一致则视为失败。
5. **改动前先落盘备份**，且备份写的是注册表原文（不是 `echo %PATH%` 展开后的结果），可直接用于还原。
6. **不写全局 `PYTHONIOENCODING` 等环境变量**。那类变量会改变所有 Python 程序的控制台行为，容易引发别的工具乱码，因此改用"按需在单次会话设置"的方式。

## 四、必须知道的 4 个注意事项

1. **已打开的终端不会变**。环境变量是进程启动时继承的，现在开着的 PowerShell / CMD / IDE 仍持旧 PATH。要用新配置，**新开一个终端**，或重启 IDE。
2. **conda 升级 Python 后，`python3.exe` 会失效**。那个副本是 3.12 的启动器，若将来 `conda update python` 升到 3.13，删掉 `C:\Users\22320\bin\python3.exe` 再重新复制一份即可（不要反过来去改 conda 目录）。
3. **PowerShell 里中文输出会乱码**（控制台 GBK vs Python UTF-8），这是显示问题不是执行失败。想看清汇总行：先 `chcp 65001`，或用 Git Bash 执行，或临时 `$env:PYTHONIOENCODING='utf-8'`（只影响当前会话）。
4. **系统级 PATH 仍有 2 条损坏段**（`%SystemRo`、`t%\system32`），需管理员才能改。它们当前是**惰性无效路径**（指向不存在的目录），不影响任何命令；`system32` 已由用户级条目兜住。要彻底清理，见下节命令。

## 六、可选：系统级 PATH 清理（需管理员，本次未执行）

以**管理员**身份打开 PowerShell 后运行（幂等，可重复执行）：

```powershell
$m = [Environment]::GetEnvironmentVariable('Path','Machine')
$m = $m.Replace('%SystemRo;t%\system32;', '%SystemRoot%\system32;').Replace('%SystemRo;t%\system32', '%SystemRoot%\system32')
$items = $m -split ';' | Where-Object { $_.Trim() -ne '' } | ForEach-Object { if($_.Trim().Length -gt 3){ $_.Trim().TrimEnd('\') } else { $_.Trim() } }
$items = $items | Select-Object -Unique
$new = ($items -join ';')
if($new -notlike '*SystemRoot%\system32*'){ Write-Output '[ABORT] 未包含 system32，放弃写入'; exit 1 }
[Environment]::SetEnvironmentVariable('Path',$new,'Machine')
Write-Output ("已更新，条目数 " + ($new -split ';').Count)
```

判定要点：脚本先做 `system32` 存在性断言再写入；若断言失败会中止而不是写坏系统 PATH。**执行前请先单独备份**：

```powershell
[Environment]::GetEnvironmentVariable('Path','Machine') | Out-File "$env:USERPROFILE\.workbuddy\env-backup\machine-before.txt" -Encoding utf8
```
