# Memorize 演示录屏拍摄清单

> 适用版本：day8（D8 整合交付）
> 拍摄环境：macOS + Xcode 15+ + iPhone 15 模拟器（iOS 16+）
> 目标成片：5–6 分钟，MP4 / H.264，1920×1080 或模拟器原始分辨率，30 fps
> 重点片段：镜头 8「超时触发 → 时间到弹窗 → 点击再来一局」

> 说明：当前 Windows 复核机没有 Xcode 与 iOS 模拟器，**本清单需在 macOS 上执行**；
> 本文只定义拍摄步骤与验收标准，不构成“已录制”的结论。

---

## 一、拍摄前准备

### 1.1 环境检查

| 检查项 | 操作 | 通过标准 |
| --- | --- | --- |
| 工程可编译 | 打开 `day8/Memorize.xcodeproj`，Scheme 选 `Memorize`，设备选 iPhone 15 | `⌘B` 无红色错误 |
| 测试证据 | 运行 `xcodebuild test` 或打开 `WinTestHarness/test_results.json` | 132/132、0 失败 |
| 模拟器干净 | 删除 App 后重新安装，或至少回到主界面 | 无旧弹窗、无残留暂停状态 |
| 通知与干扰 | 模拟器内开启“勿扰”，关闭系统通知与横幅 | 录制期间无弹窗遮挡 |
| 外观一致 | 模拟器外观固定为浅色（Settings → Developer → Appearance → Light） | 全片配色统一 |
| 状态栏 | 执行下方命令统一状态栏 | 时间 9:41、电量 100%、信号满格 |

```bash
xcrun simctl status_bar booted override \
  --time "9:41" --batteryState charged --batteryLevel 100 \
  --wifiBars 3 --cellularBars 4
```

### 1.2 录制命令

**方式 A：命令行（推荐，无界面干扰）**

```bash
mkdir -p day8/录屏
xcrun simctl io booted recordVideo --codec h264 --force \
  day8/录屏/Memorize-演示-20261105.mp4
# 录制完成后按 Ctrl+C 停止
```

**方式 B：QuickTime Player**

- 文件 → 新建屏幕录制 → 选择“iPhone 15 模拟器”窗口 → 录制；
- 录制结束用“文件 → 导出”生成 MP4。

### 1.3 拍摄纪律

- 鼠标移动缓慢、点击前停留 0.5 秒，保证观众能看清点击位置；
- 每个镜头开始前静置 1 秒，结束时静置 1 秒，方便后期剪辑；
- 不要在镜头中途切换窗口或弹出菜单；
- 镜头 8 必须**一镜到底**，不允许剪辑拼接；
- 讲解词可现场口述，也可后期配音；语速控制在每分钟 180–220 字。

## 三、镜头 8：超时流程逐项验收（必录）

### 3.1 操作顺序（一镜到底）

1. 确保倒计时处于运行状态，剩余时间小于 60 秒；
2. 若使用默认构建，静置等待至 `0`（约 60 秒，可接受）；
   若使用**临时 10 秒构建**拍摄，先确认已还原计划（见 3.3）；
3. 剩余 ≤ 5 秒时，指出环形与中心数字转红；
4. 归零瞬间，画面弹出结算弹窗，标题为 **“时间到！”**，正文为 **“本局得分：N”**，
   唯一按钮为 **“再来一局”**；
5. 点击 **“再来一局”**，观察：
   - 弹窗关闭；
   - 得分归零；
   - 卡片重新错峰发牌；
   - 环形倒计时回到本局时长并重新计时；
   - 提示行恢复为“点击卡片翻开，找出全部对子”。

### 3.2 验收清单

- [ ] 镜头中能清楚看到倒计时归零；
- [ ] 弹窗标题确为“时间到！”（不是“全部配对成功！”）；
- [ ] 弹窗正文包含本局得分；
- [ ] 点击“再来一局”后弹窗消失；
- [ ] 得分归零、卡片重新发牌、倒计时重启三个结果同时可见；
- [ ] 全流程无剪辑断点、无窗口切换、无遮挡；
- [ ] 该片段单独导出备份，命名 `Memorize-超时流程-YYYYMMDD.mp4`。

### 3.3 临时缩短时长的规范（可选）

若不想在成片中等待 60 秒：

1. 复制一份工程到临时目录（不要直接改 `day8`）；
2. 仅修改 `Memorize/ViewModels/CountdownClock.swift` 中
   `CountdownDefaults.duration = 60` 为 `10`；
3. 重新编译、录制镜头 8；
4. 录制完成后删除临时副本，确认 `day8` 内文件未变化：

```bash
git -C day8 status --porcelain
git -C day8 diff -- Memorize/ViewModels/CountdownClock.swift
```

5. 成片中如需说明，可在字幕标注“演示用 10 秒倒计时，正式版本为 60 秒”。

> 禁止把缩短时长的改动提交到仓库；正式演示与答辩必须使用 60 秒版本。

## 五、常见拍摄问题

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| 录制文件没有声音 | `simctl recordVideo` 默认不采集模拟器音频 | 需要讲解时用 QuickTime 或后期配音 |
| 画面尺寸偏小 | 模拟器缩放比例过低 | 模拟器 Window → Physical Size，或改用真机录制 |
| 状态栏时间跳动 | 未执行 `status_bar override` | 按 1.1 节命令统一状态栏 |
| 弹窗一闪而过 | 误触“再来一局” | 重新开局并重录镜头 8，点击前停留 1 秒 |
| 错配翻回时动画被截断 | 录制帧率过低 | 提高帧率到 30/60 fps，关闭其他占用 GPU 的应用 |
| 录完发现时长改过 | 使用了临时 10 秒构建 | 还原代码并重新编译 60 秒版本，正式成片必须用正式构建 |

5. 保留 `xcodebuild` 终端日志与 `.xcresult`，与录屏一并归档。
